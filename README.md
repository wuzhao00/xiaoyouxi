# 筷子桥（Chopstick Bridge）

> 限量筷子编织自锁搭桥，让小动物过河——搭稳是智慧，塌了是节目。

一款基于**达芬奇自锁桥**真实力学原理的休闲解谜微信/抖音小游戏。玩家用限量筷子在河面上逐根编织——每一根都要压住前面的、被后面的压住，搭完让小动物试走：桥微微下沉稳稳撑住 = 过关；哗啦塌进河里 = 失败即内容，筷子全回收重来。

## 为什么是这个玩法

- **达芬奇自锁桥的休闲游戏化**：经过市场验证的真空白——市面上的搭桥游戏（Bridge Constructor 系）全是"节点桁架"，而"无节点自由编织自锁"是另一种机制，全网没有同类竞品
- **三条设计铁律**：答案不摆在脸上（无提示）/ 信息不藏进死里（失败讲道理）/ 可玩性长在交互回路里（做了才知道，而不是看了才知道）
- **确定性判定**：不做实时物理堆叠模拟，用编织拓扑图论判定，塌了回放高亮"肇事筷"——失败反馈讲道理，性能也稳
