# 《筷子桥》美术需求清单

> 给画图的朋友看的文档。看完这一页你就知道要画什么、多大、叫什么名字、什么时候要。
> 交付格式固定：**PNG，透明背景，sRGB，文件名全小写 kebab-case**。
> 开发基准分辨率：**竖屏 720 × 1280（9:16）**。表里的尺寸就是最终 PNG 的像素尺寸，直接按这个画。

**一句话玩法**：玩家用有限根筷子在河上编织搭桥（后放的筷子压住先放的），搭稳了小狐狸过河，塌了筷子回收重来。

**一个好消息**：M0 阶段游戏全用彩色方块占位，**一张真实美术都不需要**。所以前期你一点压力都没有，按自己的节奏来，先出 P0 那几件就行。

## 一、风格规范

| 维度 | 规范 | 说明 / 示例 |
| --- | --- | --- |
| 整体风格 | 卡通扁平（flat cartoon），矢量感，不写实 | 像儿童绘本里的插画，不是手游那种厚涂 3D 感 |
| 描边 | 外轮廓 3 到 4 px 深色描边，颜色 `#2B2118`（近黑偏暖，别用纯黑） | 内部结构线可以细一点，但不要细过 2 px，缩小后会糊 |
| 上色 | 纯色块为主，最多一层同色系暗部，**禁止复杂渐变** | 允许极轻的径向渐变做体积感，幅度别超过 15% 明度差 |
| 光源 | 统一左上打光，阴影只用一层硬边投影，方向一致 | 所有资产都要能摆在一起不打架 |
| 视角 | 2D 侧视，带 5 到 10 度微俯，能看见筷子一层压一层 | 完全正侧视会让"压叠关系"看不出来，这点很关键 |
| 线条语言 | 圆角、饱满、略微夸张比例，不要尖锐折角 | 小狐狸的头可以大一点，身体短一点，可爱优先 |
| 材质区分 | 竹筷：暖黄 + 竹节；塑料筷：冷色半透明 + 硬高光；雪糕棒：浅木色 + 圆角 + 淡木纹 | 三种筷子放在一起要一眼分得出来，玩家靠颜色认预算 |
| 动物表演 | 表情夸张，动作幅度大，允许卡通变形（挤压拉伸） | 落水、欢呼这类"翻车即内容"的瞬间要好笑 |
| UI 面板 | 米白底 + 深色描边 + 圆角，边角留 24 px 供九宫格拉伸 | 不要给按钮画固定文字，文字由程序排版，中文字体我们自己处理 |
| 分辨率与安全边 | 按 720 × 1280 的 1x 出图，边缘留 4 px 透明安全边 | 描边和影子不要被画布裁掉 |
| 禁止项 | 照片贴图、AI 生成的杂色噪点、写实纹理、英文文字、描边不闭合 | 描边不闭合会漏色，缩放后特别明显 |

### 三个场景画面参考（给风格对齐用，不是要你画这三张）

1. **主界面**：一条横穿画面的蓝色小河，左岸草坡、右岸石滩，画面正中偏上是木质感的游戏标题，下面三个圆角按钮（开始、每日挑战、图鉴），小河上方飘两朵白云，一只小狐狸蹲在左岸歪头看镜头。
2. **搭桥中**：小河横贯画面中部，河心一块圆石，玩家已经放了三根竹筷，两根横跨、一根斜压在上面，筷子之间有明显投影说明谁压谁，右上角一个小木牌显示"剩余筷子 5"，小狐狸在左岸紧张地前倾。
3. **塌桥瞬间**：筷子从中间断开向河里掉，水花四溅，肇事的那根筷子整体描红（`#FF3B30`），小狐狸在岸上四脚离地后仰，表情惊恐但好笑，绝对不能画得血腥或让人不适。

## 五、命名与交付规则

| 规则 | 要求 | 反例 |
| --- | --- | --- |
| 文件名格式 | 全小写，单词用连字符 `-` 连接，扩展名 `.png` | `BambooStick.PNG`、`筷子.png`、`bamboo stick.png` |
| 前缀分组 | `bg-` 背景、`stick-` 筷子、`fox-` 狐狸、`prop-` 场景道具、`fx-` 特效、`ui-` 界面、`icon-` 小图标、`card-` 卡片、`badge-` 角标、`ad-` 广告、`store-` / `promo-` 商店素材 | `图片1.png` |
| 序列帧 | 横向排列精灵表，每帧宽度相等，画布高度一致；单体序列也可用 `fox-idle-01.png` 这种编号 | 竖排、帧宽不等、每帧单独裁到内容边界 |
| 尺寸 | 必须是 2 的倍数（表格里已满足），不要自行放大缩小 | 383×97 |
| 颜色模式 | sRGB，8 bit/通道，PNG-24 带 alpha | CMYK、索引色、16 bit |
| 透明背景 | 除 `bg-river.png`、`bg-map.png` 铺满整屏可自带底色外，其余全部透明底 | 白底图直接给过来 |
| 描边完整 | 四周留 4 px 透明安全边，描边不许被裁 | 贴边裁切导致缩放后漏白 |
| 单文件体积 | 普通素材 ≤ 300 KB，整屏背景 ≤ 500 KB（首包只有 4 MB，得省着花） | 一张 3 MB 的背景图 |
| 文字 | 所有素材**不要烤进文字**（Logo 除外），中文由程序渲染 | 把按钮文字画在图里 |
| 交付物 | 原始 PNG + 一份文件名清单（txt 或表格都行）+ 一张拼图预览 | 只发一张合并大图 |
| 版本 | 改动过的文件在后面加日期，如 `stick-bamboo-1113.png`，别直接覆盖 | 反复覆盖同一个文件名找不到历史 |

## 六、直接发给朋友的说明（可整段复制）

> 嗨～麻烦你帮《筷子桥》画美术啦。这是个微信和抖音上的小游戏，玩法是用限量筷子在河上编一座桥，让一只小狐狸走过去，画风就是卡通扁平那种，粗描边、亮颜色、可爱优先，不用写实。
>
> 最急的只有五件（表里标了 P0）：竹筷、塑料筷、雪糕棒三种筷子的贴图，一只小狐狸的待机动画，还有一张河面加两岸的整屏底图。这五件到了游戏就能跑起来，剩下的咱们按里程碑慢慢补，不急。
>
> 尺寸、文件名、透明底这些我在文档的表格里都写死了，你照着来就行，PNG 透明背景，按表里的像素尺寸直接画。特别注意两点：一是筷子要有明显的投影和描边，因为玩家得靠这个看出谁压着谁；二是有个红色 `#FF3B30` 是程序要采样的高亮色，别改。
>
> 进度上你完全不用有压力，我们开发阶段全用彩色方块占位，M0 阶段一张真实美术都不需要，你按自己节奏走，先出那五件 P0 就行。
>
> 有尺寸或风格上的疑问随时喊我，画完把原始 PNG 加上一份文件名清单发我就好，辛苦啦～
